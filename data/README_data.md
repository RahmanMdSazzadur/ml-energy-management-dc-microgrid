## Spot prices

The study used Finnish day-ahead prices (EUR/MWh, hourly, UTC) for 2019-2024. They are not included
because the copy used was obtained under a private-use licence. To reproduce the results:

1. Download Finland (bidding zone FI) day-ahead prices for 2019-2024 from the
   [ENTSO-E Transparency Platform](https://transparency.entsoe.eu/) (free account; API or CSV export).
2. Save them as `data/raw/spot_price_FI_2019_2024_hourly.csv` with columns `time_utc,price_eur_mwh`.
3. Run `python -m src.data.clean` and `python -m src.data.make_homer_inputs`, then the commands in the main README.

Files that contain prices (processed inputs, HOMER price files, the `.homer` project, hourly results)
are regenerated by these steps and are therefore excluded from the repository.
